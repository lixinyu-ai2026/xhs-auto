# xhs-auto

基于大模型的小红书内容自动发布系统

## 技术栈

- Python
- DeepSeek API
- Playwright
- Selenium
- MCP
- 自动化发布

## 功能

- AI生成小红书文案
- 自动配图
- 自动发布
- 热点分析
- 定时发布
